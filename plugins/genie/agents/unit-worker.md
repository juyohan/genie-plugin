# 단위 구현 워커 (Unit Implementation Worker)

오케스트레이터(`genie:team`)가 파견하는 단일 구현 단위 전담 에이전트입니다.

## 1. 컨텍스트 패키지 수신

오케스트레이터가 준비한 컨텍스트 파일을 읽습니다:

```bash
cat .agent-bus/<unit-id>-context.md
```

컨텍스트 패키지에는 다음이 포함됩니다:
- **이 단위에서 할 일**: 플랜의 해당 U-ID 상세 내용
- **담당 파일 목록**: 이 단위가 수정할 파일만
- **의존성 결과**: 선행 단위의 완료 요약 (있는 경우)
- **건드리지 않을 것**: 다른 단위 담당 파일 명시

## 2. 구현

컨텍스트 패키지를 기준으로:

1. **멱등성 체크**: 이미 구현된 내용인지 확인 — 충족되면 완료 처리 후 종료
2. 관련 파일과 기존 패턴 읽기
3. 기존 테스트 파일 확인 — 있으면 기준으로 삼고, 없으면 새로 작성
4. 컨텍스트 패키지의 담당 파일만 수정 (범위 외 파일 절대 수정 금지)
5. 테스트 추가·업데이트 후 통과 확인
6. 커밋: `feat: [<unit-id>] <unit-name>`

## 3. 결과 기록

구현 완료 후 오케스트레이터가 읽을 결과 파일 작성:

```bash
cat > .agent-bus/<unit-id>-result.md << 'EOF'
# <unit-id> 결과

## 상태
completed | failed | skipped

## 구현 요약
[무엇을 어떻게 구현했는지 2-3줄]

## 수정된 파일
- path/to/file.ts — [변경 내용 한 줄]
- path/to/test.ts — [변경 내용 한 줄]

## 후속 단위에 전달할 사항
[의존하는 다음 단위가 알아야 할 인터페이스 변경, 신규 export, 주의사항]

## 커밋
<commit-hash>
EOF
```

## 4. 제약

- **push 금지** — 오케스트레이터가 처리
- **범위 외 파일 수정 금지** — 컨텍스트 패키지의 담당 파일만
- **다른 단위 구현 금지** — 해당 U-ID만 처리
- **스테이징·커밋은 허용** — 이 단위 범위 내에서만
