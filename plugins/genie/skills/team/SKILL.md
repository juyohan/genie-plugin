# 팀 병렬 실행 (Team Parallel Execution)

<input_document> #$ARGUMENTS </input_document>

`--add gemini` (또는 `--add gem`) 플래그가 있으면: gem 도구로 Gemini에 의존성 그래프 검토 요청 후 결과 통합.

## 1. 플랜 로드

1. `$ARGUMENTS`가 파일 경로면 해당 플랜 사용. 비어 있으면 `docs/plans/`에서 가장 최근 `status: active` 플랜 선택
2. 플랜이 없으면 안내 후 종료:
   > "`/genie:plan`으로 플랜을 먼저 작성하세요."
3. 플랜의 `Implementation Units` 섹션에서 추출:
   - 각 U-ID, 이름, 담당 파일 목록
   - `Depends on:` 필드 (없으면 독립 단위)

## 2. 의존성 그래프 및 웨이브 구성

추출한 단위로 DAG(방향 비순환 그래프)를 구성하고 웨이브를 산출합니다:

```
웨이브 N = 이전 웨이브에서만 의존하거나 의존성 없는 단위들의 집합
```

분석 결과 출력 예시:
```
웨이브 1 (병렬 3): U1 · U2 · U4
웨이브 2 (병렬 2): U3 · U5
웨이브 3 (직렬 1): U6
총 3 웨이브
```

**단위가 2개 이하이거나 모든 단위가 선형 종속이면:**
> "병렬화 이점이 없습니다. `genie:work`를 대신 사용하는 것을 권장합니다."
계속 진행 여부를 사용자에게 묻습니다.

## 3. 웨이브 실행

각 웨이브를 순서대로 실행합니다. 웨이브 내 단위들은 병렬 처리합니다.

### 3-1. 파일 겹침 확인

웨이브 내 단위들의 파일 목록을 교차 확인합니다.

- 겹치는 파일 없음: 모든 단위 병렬 실행
- 겹치는 파일 있는 단위들: 직렬로 강등하고 사유 출력
  ```
  U3 · U5 → 직렬 강등 (파일 겹침: src/shared/utils.ts)
  ```

### 3-2. 워크트리 생성 및 에이전트 파견 (병렬 단위)

각 병렬 단위에 대해:

**워크트리 생성:**
```bash
bash "${CLAUDE_SKILL_DIR:-.}/scripts/worktree-manager.sh" create team/<unit-id>
# 예: team/U1, team/U2, team/U4
```

**서브에이전트 파견** (`isolation: "worktree"`, `run_in_background: true`):

서브에이전트 지시사항:
- 해당 워크트리 디렉토리에서 작업
- 플랜의 해당 U-ID 단위만 구현 (다른 단위 건드리지 않음)
- 기존 패턴 따라 구현 → 테스트 작성/업데이트 → 테스트 통과 확인
- 워크트리 내에서 커밋: `feat: [U<N>] <unit-name>`
- 스테이징·커밋·테스트 실행만 허용. push 금지

모든 서브에이전트 완료까지 대기합니다.

### 3-3. 직렬 단위 인라인 실행

직렬로 강등된 단위는 워크트리 없이 현재 브랜치에서 직접 구현합니다. (`genie:work` 실행 로직과 동일)

### 3-4. 병합

병렬 단위 완료 후 의존성 순서대로 현재 브랜치에 병합합니다:

```bash
git merge --no-ff team/<unit-id>
```

충돌 발생 시:
1. 충돌 파일과 관련 단위를 출력합니다
2. 충돌을 직접 해결하고 커밋합니다
3. 해결 불가능하면 해당 단위를 직렬로 재실행합니다

**병합 직후 즉시 테스트 실행:**
```bash
# 프로젝트 테스트 스위트 실행 (npm test, pytest, go test 등)
```
실패 시 즉시 수정 후 재실행합니다.

### 3-5. 워크트리 제거

병합 완료된 워크트리를 제거합니다:
```bash
git worktree remove .worktrees/team/<unit-id>
```

## 4. 최종 검증

모든 웨이브 완료 후:

1. 전체 테스트 스위트 실행
2. 린터 실행
3. 플랜의 `Requirements` 항목 전체 충족 여부 확인
4. 플랜 frontmatter `status: active → completed` 전환

## 5. 완료 보고

```
팀 실행 완료
  웨이브:    3 (총 6개 단위)
  병렬 처리: U1 · U2 · U4 / U3 · U5
  직렬 처리: U6
  다음 단계: /genie:review
```

`/genie:review`를 다음 단계로 권장합니다.
