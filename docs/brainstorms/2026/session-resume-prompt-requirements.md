# Session Resume Prompt — Requirements

**작성일**: 2026-05-26
**상태**: Draft
**다음 단계**: `/genie:plan`

---

## 배경

Claude Code는 세션 데이터를 `~/.claude/projects/<project>/` 에 JSONL로 자동 저장한다.
그러나 사용자가 새 세션을 시작할 때 이전 세션이 있다는 사실을 인지하지 못하거나,
`/resume-session` 명령 존재 자체를 잊는 문제가 있다.

---

## 목표

새 세션 시작 시 **자동으로** 이전 세션 존재를 감지하고,
사용자가 별도 명령 없이 이어서 작업할 수 있도록 한다.

---

## Actors

- **A-1** 사용자 — `claude` 명령으로 새 세션을 시작하는 사람
- **A-2** `session-start.js` 훅 — SessionStart 이벤트에서 실행되는 자동화 컴포넌트

---

## Requirements

### R-1 세션 감지 조건
같은 프로젝트 디렉토리 (`cwd`) + **6시간 이내**에 종료된 세션이 존재할 때만 프롬프트를 표시한다.
두 조건 중 하나라도 충족하지 않으면 아무 동작도 하지 않는다.

### R-2 프롬프트 메시지
조건 충족 시 아래 형식으로 출력한다:

```
N분 전 세션이 있습니다. 이어서 할까요? (y/n)
```

- N은 마지막 세션 종료 후 경과 시간 (분 단위)
- 요약·내용 미리보기 없음 — 메시지는 심플하게 유지

### R-3 Yes 응답 처리
사용자가 `y` (또는 `yes`) 응답 시:
- 해당 JSONL 파일에서 마지막 교환 내용을 읽어 Claude의 초기 컨텍스트로 주입
- 별도 스킬 호출 없이 훅 내부에서 완결

### R-4 No 응답 처리
사용자가 `n` (또는 `no`, 또는 엔터) 응답 시:
- 아무 동작 없이 새 세션 시작

### R-5 다중 세션 처리
6시간 이내 세션이 여러 개일 경우 **가장 최근 것** 하나만 사용한다.

### R-6 오류 무시
JSONL 읽기 실패, 파싱 오류 등 모든 예외는 조용히 무시하고 새 세션을 정상 시작한다.
훅 오류가 세션 시작을 막아서는 안 된다.

---

## Key Flows

### F-1 정상 흐름 (감지 → 이어서)
```
사용자: claude 실행
  → session-start.js: cwd + 6시간 이내 JSONL 탐색
  → 발견: "23분 전 세션이 있습니다. 이어서 할까요? (y/n)"
  → 사용자: y
  → JSONL 마지막 교환 읽어 컨텍스트 주입
  → 세션 시작 (이전 내용 인지 상태)
```

### F-2 거절 흐름
```
  → 사용자: n (또는 엔터)
  → 컨텍스트 주입 없이 새 세션 시작
```

### F-3 조건 미충족 흐름
```
  → session-start.js: 6시간 이내 같은 디렉토리 세션 없음
  → 프롬프트 없이 세션 시작
```

## Acceptance Examples

### AE-1
**Given** 같은 디렉토리에서 23분 전에 종료된 세션이 있음
**When** `claude` 실행
**Then** `"23분 전 세션이 있습니다. 이어서 할까요? (y/n)"` 출력

### AE-2
**Given** AE-1 상황에서 사용자가 `y` 입력
**Then** 이전 세션의 마지막 교환이 컨텍스트에 포함된 상태로 세션 시작

### AE-3
**Given** AE-1 상황에서 사용자가 `n` 입력
**Then** 컨텍스트 주입 없이 새 세션 시작

### AE-4
**Given** 마지막 세션이 7시간 전에 종료됨
**When** `claude` 실행
**Then** 프롬프트 없이 새 세션 시작

### AE-5
**Given** 같은 디렉토리가 아닌 다른 프로젝트에서의 세션만 존재
**When** `claude` 실행
**Then** 프롬프트 없이 새 세션 시작

### AE-6
**Given** JSONL 파일이 손상되어 파싱 불가
**When** 사용자가 `y` 입력
**Then** 오류 없이 새 세션 정상 시작 (컨텍스트 주입만 생략)

---

## 범위 밖

- AI 요약 생성 없음 (단순 교환 주입만)
- 다른 디렉토리 세션 탐색 없음
- `/save-session` 스킬 대체 없음 (별도 용도 유지)
- 세션 목록 선택 UI 없음 (항상 가장 최근 것)
